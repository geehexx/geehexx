# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities via public GitHub issues.

Instead, use [GitHub private vulnerability reporting](https://github.com/geehexx/geehexx/security/advisories/new) to disclose the issue privately.

Include as much detail as possible:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations

You will receive a response within 7 days. If the issue is confirmed, a fix will be prioritised and a public advisory published once resolved.
